# Milestone 0 — Orientation & Setup

## Project Environment

This project was developed using Kaggle for competition-style experimentation, training, inference, and benchmarking.

## Tools

- Kaggle — dataset access, model experimentation, inference, and submission
- GitHub — source-code organization and version control
- Weights & Biases (W&B) — experiment tracking
- Hugging Face — transformer models and related libraries

## Project Setup

The project uses Python and common machine learning / NLP libraries for:

- Data loading and manipulation
- Text preprocessing
- TF-IDF feature extraction
- Machine learning model training
- Transformer-based experiments
- Evaluation using MAP@3

## Repository Organization

The project code is organized according to the project milestones:

- Milestone 1 — NLP Foundation & Semantic Similarity
- Milestone 2 — Transformers
- Milestone 3 — Context Augmentation with RAG Pipelines
- Milestone 4 — MCQ Task & Fine-Tuning
- Milestone 5 — Ensembling
- Final Submission — Final Kaggle inference and submission

## Environment Notes

The original experiments were performed in the Kaggle environment. Kaggle-specific paths and notebook commands will be separated from the reusable project code during the GitHub organization phase.
